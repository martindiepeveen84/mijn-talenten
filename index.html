Veelgestelde vragen

Is de test wetenschappelijk?

De test is gebaseerd op het Big Five-model. Dat is het meest onderzochte model voor persoonlijkheid. De stellingen komen uit een vrije wetenschappelijke bron (de IPIP). De Nederlandse vertaling is niet apart onderzocht. Lees meer op de uitlegpagina.

Is dit de TMA?

Nee. De TMA is een apart, betaald instrument. Deze test is korter en werkt anders. Je kunt de uitslagen niet één op één vergelijken.

Wordt mijn uitslag ergens bewaard?

Nee. Alles gebeurt in je eigen browser. De uitslag staat alleen in het adres van de pagina. Dat adres gaat niet naar een server.

Kan mijn leidinggevende zien wat ik heb ingevuld?

Nee. Alleen als je zelf je uitslag deelt.

Mag je de test gebruiken bij sollicitaties of beoordelingen?

Nee. De test is gemaakt voor ontwikkeling en gesprek, niet voor selectie of beoordeling.

Kan ik de test vaker doen?

Ja. Je uitslag is een momentopname. Je kunt de test na een tijd opnieuw doen en kijken wat er is veranderd.
